# Plant Disease Detection - End-to-End Deep Learning Project 

This project aims to identify plant diseases using image classification with CNN and provide a mobile app that allows farmers to capture a plant image and receive instant disease diagnosis.

## Technology Stack

Model Building	TensorFlow, CNN, Data Augmentation, tf.data.Dataset
Backend & ML Ops	TensorFlow Serving, FastAPI
Model Optimization	Quantization, TensorFlow Lite
Frontend	React.js (Web), React Native (Mobile)

## Model Performance and accuracy:
Accuracy = 99.5 %

Loss Reduction: Minimal overfitting due to data augmentation and dropout layers.
Confusion Matrix Insights: High recall and precision, ensuring minimal false positives and false negatives
